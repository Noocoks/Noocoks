## 06 / HOW I WORK

- **Build to understand.** I prefer practical experiments and working prototypes over theory alone.
- **Design for people.** Clear workflows and accessible interfaces matter as much as the underlying code.
- **Treat security as part of engineering.** Validate inputs, review dependencies, test boundaries and automate checks where possible.
- **Document the process.** Notes and repeatable procedures turn individual discoveries into reusable knowledge.
- **Keep improving.** Refactoring, responsive behaviour, accessibility and maintainability are ongoing work.
